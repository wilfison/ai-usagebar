# Features

* [Pace](pace.md) - Pace states, verdicts and the colours past the marker.
* [Usage trend](usage-trend.md) - A line of recent readings under each usage window, sampled on fresh fetches.
* [Notifications](notifications.md) - Threshold and reset-credit notifications with deduped state.
* [Update check](update-check.md) - Daily GitHub releases check and the popup link.
* [Provider status](provider-status.md) - Claude and Codex cards marked from their official status page.
* [Context monitor](context-monitor.md) - Claude Code session context usage in the Anthropic section.
* [Custom provider](custom-provider.md) - Any JSON endpoint mapped into a vendor through JSON Pointer.
