# Rules

- `metadata.json` declares `gettext-domain` `ai-usagebar@wilfison`, so the shell initializes translations for both `extension.js` and `prefs.js`.[^metadata]
- Every user-facing string is `_('plain literal')`; never a template literal, which `xgettext` cannot extract.
- gi-bound modules import the real `_`: `ui/indicator.js` from `resource:///org/gnome/shell/extensions/extension.js`, `prefs.js` from `resource:///org/gnome/Shell/Extensions/js/extensions/prefs.js`.
- **Pure modules never import gettext.** `lib/countdown.js`, `section-common.js` and every vendor `section.js` take a trailing `_ = (s) => s`; builders with plurals also take `ngettext`: the Anthropic, OpenAI and OpenRouter sections and the Anthropic and OpenAI `placeholders`. The indicator injects the real ones when it calls the adapter. Extraction is syntactic, so the strings are still found.
- Interpolate with `vformat()` from `lib/format.js` (`%s`, `%d`, `%02d`, `%%`): `String.prototype.format` is missing in the prefs process and in bare `gjs -m`.
- Not translated: brand names (wrapped in prefs only, with a "keep untranslated" translator comment), `{token}` names, specifiers, short codes, colours, money strings.
- The renderer `ui/vendorSection.js` stays string-free ([vendor adapters](/architecture/vendor-adapters.md)).

# Catalogs

`po/` holds the `.pot` and the `pt_BR`, `es`, `fr`, `de` sources; `locale/<lang>/LC_MESSAGES/*.mo` is gitignored build output. The `.pot` records only file locations (`--add-location=file`) so code edits do not dirty it.

# Adding a string

```bash
make pot && make update-po          # extract, merge
make i18n-todo                      # untranslated / fuzzy per catalog
./tools/i18n.sh fill t.json         # {msgid: {lang: text}}: set, clear fuzzy, rewrap
make i18n-check                     # CI gate
```

Reuse existing catalog terms; check with `msgcat --no-wrap po/<ll>.po | grep -A1 'msgid "Vendors"'`. A new language is `msginit --input=po/ai-usagebar@wilfison.pot --locale=<ll> --output=po/<ll>.po`, translated and shipped; no code change.[^i18n]

# Verifying

The session locale is fixed, so `make reload` does not switch language. Use `make compile-locale`, then `make headless LANG_UNDER_TEST=pt_BR FAKE_PCT=40` or `env LANG=pt_BR.UTF-8 LANGUAGE=pt_BR make run`. Only locales in `locale -a` start. See [headless shell](/development/headless.md).
